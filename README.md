## Featured

**[Macro Desk](https://github.com/john-stromberg/macro-lens)** — Open source · [Live demo](https://john-stromberg.github.io/macro-desk/)

Macro hedge fund PM and research desk: fund book with factor risk and P&L, living theses, catalyst calendar, scenario shock packs, and market tools for surprises, curves, policy, regimes, and cross-asset tape.

- Book view with AUM, gross/net, VaR, and sleeve filters
- Theses linked to live expressions and upcoming catalysts
- Scenario lab with estimated fund P&L winners and losers

**[econkit](https://github.com/john-stromberg/econkit)** — Open source

R toolkit for applied economic analysis in asset management and banking: turn macro and market data into recession risk, regime signals, scenario stress, rate and credit analytics, and governed reports.

- Recession models, Sahm rule, nowcasts, and Minnesota-prior BVAR forecasts
- Scenario libraries with SAA stress, ALM NII/EVE, FTP, and lifetime ECL workflows
- Optional plumber API with model inventory, run lineage, and monitoring

**value-creation** (`pevc`) — Private · source available on request

Python toolkit for middle-market PE operating partners and deal teams: load portfolio-company financials, diagnose value leakage, size a value creation plan (VCP), and translate it into sponsor returns via library, CLI, and Streamlit dashboard.

- Diagnostics, pricing, working capital, commercial retention, contracts, pipeline, and operations / OEE
- Initiative register and VCP planning with LBO returns and Monte Carlo risk
- Excel analysis packs and audience-specific investment package drafts
