# Research and financial software

Independent projects covering portfolio construction, fixed-income analytics,
econometrics, advisor workflows, and financial planning.

## Project collections

- [Portfolio Analytics](https://github.com/john-stromberg/portfolio-analytics) -
  optimization, rebalancing, risk, and related research.
- [Fixed Income Analytics](https://github.com/john-stromberg/fixed-income-analytics) -
  bond, credit, mortgage, and trading analytics.
- [Quantitative Research in R](https://github.com/john-stromberg/quant-research-r) -
  econometrics, forecasting, factors, and allocation.
- [Advisor Platform](https://github.com/john-stromberg/advisor-platform) -
  independent .NET advisor workflow projects.
- [Wealth Planning Apps](https://github.com/john-stromberg/wealth-planning-apps) -
  planning calculators, dashboards, and a financial data pipeline.
